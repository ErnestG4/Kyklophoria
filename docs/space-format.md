# Space file format `*.kyk` — version 1

A space is one binary blob: a 64-byte header followed by hyperpoints. Little
endian throughout, float32 values. The core (`core/kyk_space.h`) views the
blob in place — on the module it is loaded from SD into SDRAM; on the desktop
into a vector. `tools/kykspace gen|info` writes and validates files.

## Header (64 bytes)

| offset | type | field | meaning |
|---|---|---|---|
| 0 | u32 | `magic` | `"KYK1"` = `0x314B594B` |
| 4 | u16 | `version` | 1 |
| 6 | u8 | `n` | dimensions, 1..6 |
| 7 | u8 | `mode` | 0 lattice · 1 scattered (reserved, M5) |
| 8 | u8 | `k` | harmonics per point, 1..128 (harmonics 1..K, no DC) |
| 9 | u8 | `p` | payload lanes, 0..8 |
| 10 | u8 | `side` | lattice points per axis, ≥ 2 |
| 11 | u8 | `flags` | bit0: per-point phases stored (reserved; the M0 core rejects nothing but ignores them) |
| 12 | u8[6] | `topo` | per axis: 0 clamp · 1 wrap · 2 sphere |
| 18 | u8[2] | pad | 0 |
| 20 | u32 | `phase_seed` | 0 = zero phases; else xorshift32 seed for the derived per-harmonic phases |
| 24 | u32 | `point_count` | lattice: must equal `side^n` |
| 28 | char[32] | `name` | NUL-padded |
| 60 | u32 | `reserved` | 0 (M5: offset of the triangulation block) |

## Hyperpoints

`point_count` records, each `k` floats of magnitude (harmonic 1 first),
then `k` floats of phase if `flags & 1`, then `p` floats of payload. The
record stride is therefore `k·(1 or 2) + p` floats.

Lattice order: axis 0 fastest (`idx = Σ ix[a] · side^a`).

Magnitudes are linear amplitudes; the generator RMS-normalises each point
(`Σ m² = 2`, unit RMS when rendered). Payload values are 0..1 and are
interpreted by the lanes (spec §3.5).

## Phases
With `phase_seed = 0` every harmonic has zero phase — a cosine stack, peaky
and a poor default. Any other seed fixes one random phase per harmonic for
the whole space, quantised to 2π/2048 (the sine table), identical on every
target. The alternative, storing phases per point, doubles the record and
interpolates poorly between cells (magnitude cancellation as phases
disagree); it stays reserved until a generator needs it (spec §9.3).

## Payload lanes as generated by the Harmonic family (M0)

| lane | meaning | function of lattice position `u` |
|---|---|---|
| 0 | cutoff | `1 − tilt` |
| 1 | resonance | `formant` |
| 2 | fm index | `shape · hollow` |
| 3 | drive | `shape` |
| 4 | cv out A | `hollow` |
| 5 | cv out B | distance from the centre of the space |
| 6 | spare | `0.5 + 0.5(shape − tilt)` |
| 7 | spare | `formant · (1 − hollow)` |

## Sizes
`64 + side^n · (k + p) · 4` bytes. N=4, side=4, K=64, P=8 → 73,792 bytes.
N=6, side=4, K=64 → 1.18 MB (SDRAM is 64 MB).

## Versioning
`version` bumps on any header change; new fields go into `reserved` first.
Scattered mode (M5) adds a triangulation block after the points, located by
`reserved`. A latent-decoder bake (later) emits a lattice or scattered file
like any other generator — nothing in the format is generator-specific.
