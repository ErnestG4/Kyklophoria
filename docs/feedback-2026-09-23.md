## PRIMARY: Strike, Body and Ring controls between knobs, web and device

> Primary thing we need to fix before all others: The Strike, Body, and Ring
> options don't seem to be applying or mapping properly between the knobs,
> the web, and the device. This is a problem for testing the VEL groups
> especially.
>  -knobs are crossed, the sliders misrepresent, and strike VEL on the page
>  doesn't seem to have any impact (no pun intended ;))

## SECONDARY: local reconstruction, our own exciters

> Secondary, we need to push for local reconstructions in the physical synth
> where possible because we can control all parameters there. Drop it
> underwater. Turn it to wood. IDK. Either way modeling our own strikes and
> perfecting the waveguide seems like the way to go. Open to discussion but a
> control surface similar to elements would be nice to have, and that means
> owning the exciter range from blow to bow to reed to buzz(brass) to pluck to
> strike etc. etc.

## Multi-string instruments: a standard layout and a neck control

> Instruments with multiple strings measured should be set to a standard
> scale (not musical scale, but which note on which string) and then a knob to
> move up or down the neck or something similar? We need to think about it
> but that idea is close. For example, a guitar would be something like frets
> 0-5, 0-5, 0-5, 0-5, 0-4, 0-end-of-neck right?

## Module: world slots

> Only 8 world slots can be filled then others fail. It doesn't matter which

## Fitting: smoothness across notes

> Over all of our training sets, is there a way to smooth across each note as
> well? I think that would fix a lot of our models. IE there are some timbre
> jumps when the physics should be similar. Again the Wurli has wildly
> different notes side by side (resonance/timbre wise). It's like notes are
> grouped into resonance groups and they all act the same. Each note is
> unique, always.

## Clean and normal both stay

> I think both clean and normal versions of the instruments have their place.
> One is much richer and the other may sit better as a compliment in a mix.
