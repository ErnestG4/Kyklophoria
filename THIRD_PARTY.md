# Third-party material

Kyklophoria itself is AGPL-3.0 (`LICENSE`). Everything below is a build-time
sibling or a bake-time input rather than vendored source, with one exception
that is listed as its own row because it is not hypothetical: a *derivative* of
the Braids bank is committed here and ships in the firmware. See "Baked in".

## Build-time siblings, not redistributed here

| | licence | how it is used |
|---|---|---|
| [alchemy-sdk](https://github.com/hermetic-modular/alchemy-sdk) (Hermetic Modular) | MIT | the Alchemy Lab BSP and framework; the firmware links against it, and `shell/common/kyk_ext.h` compiles against its header-only HostLink wire layer |
| [libDaisy](https://github.com/electro-smith/libDaisy) (Electrosmith) | MIT | vendored inside the SDK; CMSIS-DSP arrives with it |
| [Audiothurgist](https://codeberg.org/combust/Audiothurgist) | AGPL-3.0 | same author. The Alchemy Lab shell pattern, the HostLink extension approach and the web wire layer in `web/link.js` derive from it |

MIT permits inclusion in an AGPL work, so the combined firmware is
distributable under AGPL-3.0 with the MIT notices preserved. Both upstreams
ship their own `LICENSE`; neither is copied here because neither is copied
here.

## Bake-time corpora

`tools/kykeigen` reads a corpus and emits a `*.kyk` space. The corpus is an
input to an analysis, not a dependency of the firmware, and the tool does not
copy corpus source into its output — a baked space holds principal components
of log-magnitude spectra, not waveforms.

| corpus | licence | note |
|---|---|---|
| [Braids](https://github.com/pichenettes/eurorack) wave bank, Émilie Gillet / Mutable Instruments | MIT | 256 single cycles read from `braids/resources.cc` in a sibling checkout. The first corpus the eigenspace was baked from |

## Baked in, and shipped

| artefact | source | licence | what it is |
|---|---|---|---|
| `core/kyk_eigen_basis.h` | the Braids wave bank, Émilie Gillet / Mutable Instruments | MIT | Committed to this repository and compiled into the firmware as world 0, **Crop**. Generated by `tools/kykeigen` from the 256-cycle bank: a mean log-magnitude spectrum of 64 numbers and four principal-component vectors of 64 each, carrying 68.6% of the log-spectral variance. Derived statistics — no waveform samples, no audio, 55 lines of float constants. |

An earlier version of this file said that nothing here was vendored and that
credit would be due "if a baked space derived from Braids is ever shipped". It
is shipped, and has been since the eigenspace became a world: the conditional
was written before the bake was committed and never revisited. Crediting Émilie
Gillet is therefore not conditional. The README does it, the world's own
description in `core/kyk_worlds.h` does it, and this table does it.

The world was called "Braids" until 2026-09-13 and is now called **Crop**,
because four principal components of a bank sound like neither the bank nor the
instrument it came from, and naming it after somebody else's product was a
liberty. The credit moved with it rather than away.

## Not used

No npm packages. No pip packages. The tooling is C++ and the Python standard
library; the four node files under `web/` and `tools/` use only node's
built-in modules and are optional twins of the Python ones.
